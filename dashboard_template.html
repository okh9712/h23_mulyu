015/16/17L FAB 구조 (Bridge / Lifter)

16L – 15L – 17L 순으로 동(Line)이 배치되고, 각 라인은 상부층/하부층으로 구성됩니다. 동간 이동은 Bridge, 층간 이동은 Lifter. 색상은 예측기간(27~28년) 최대 부하율 기준 상태입니다.

1·2이력 데이터 / 중장기 생산계획 입력 (Excel 업로드)

기본값은 PoC용 더미 데이터입니다. 생산계획이 변경되면 엑셀의 월별_생산계획 시트를 수정해 업로드하세요. 업로드한 계획은 브라우저에서 즉시 재예측(Ridge 선형모델)됩니다.

① 26.1~26.10 이력 데이터 (시트: 일별_생산계획_WIP, 일별_물동량)
샘플 Excel
② 27.1~28.12 중장기 생산계획 (시트: 월별_생산계획 / 년월·라인·제품·생산계획(Lot))
샘플 Excel
부하율 = 월 평균 Lot/Hr × 피크 계수 ÷ MAX CAPA (1.00 = 월평균 기준, 시간대 편차를 보려면 1.1~1.3 등으로 조정)

3각 Line별 생산계획 / 재공(WIP) 현황

월별 제품별 생산계획(막대, Lot)과 평균 재공(선, Lot). 27년 이후 재공은 이력의 재공/계획 비율로 추정한 값입니다.

7라인/층별 물동량 Matrix (FROM → TO)

행 = 출발(FROM), 열 = 도착(TO). 같은 라인 내 상·하부 이동 = Lifter, 라인 간 동일 층 이동 = Bridge.

8Bridge / Lifter 부하율

부하율 = 월 평균 Lot/Hr × 피크계수 ÷ MAX CAPA. 100% 초과 시 병목 발생 우려.
